# 粒子圣诞树

白粉色粒子圣诞树 + 白色螺旋光绳，开场由星尘飞聚成树。单文件、零依赖、双击即可打开。

## 在线看

把本仓库开启 GitHub Pages 后，访问 `https://<你的用户名>.github.io/<仓库名>/` 即可。

## 改名字

用记事本打开 `index.html`，改动顶部这一行：

```js
var NAME = "西米露";
```

保存后刷新页面即生效。

## 说明

- 纯原生 Canvas + WebGL，不引用任何外部库、字体、图片
- 自适应任意窗口尺寸
- 用 Chrome / Edge / Firefox 打开，需开启硬件加速（WebGL）
